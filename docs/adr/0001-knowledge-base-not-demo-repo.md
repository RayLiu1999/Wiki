# 知識庫，不是 demo 庫

DevWiki 的價值在於把技術原理講清楚，而不是提供可執行的範例專案。因此不再做執行驗證：移除 `verifiedWith`、C# 範例比對與片段同步檢查，也移除實作指南、`examples/` 與 `lab:*` 實驗環境。正確性改以「文中每個指令、指標名稱與設定鍵都能追溯到該篇列出的官方來源」為底線。原因是實驗環境的維護成本高、只覆蓋少數文章，而且在改寫過程中讓 `verifiedWith` 出現了 30 篇沒有依據的「實測」宣稱，留著不維護的驗證反而傷害可信度。

## Consequences

- 文章中的程式碼是說明用的片段，不保證能直接編譯；讀者要帶回自己的專案調整。
- 雲端排查同時涵蓋 GKE（GCP）與 EKS（AWS）及其託管服務。
- 網站本身的檢查（型別、lint、文章結構、建置、網站容器）不受影響，它們保護的是網站，不是範例。
